================================================================================
          HƯỚNG DẪN CÀI ĐẶT VÀ CHẠY DỰ ÁN FRONTEND TRÊN MÁY TÍNH MỚI
               HỆ THỐNG GIÁM SÁT SẢN XUẤT SCADA & MES (DRC / SHTECH)
================================================================================

Tài liệu này hướng dẫn chi tiết từng bước để tải thư viện (node_modules), cấu hình 
và khởi chạy dự án frontend React + Vite trên một máy tính mới từ đầu.

--------------------------------------------------------------------------------
MỤC LỤC:
  1. Yêu cầu môi trường máy tính (Prerequisites)
  2. Chuẩn bị thư mục mã nguồn dự án
  3. Cài đặt các thư viện phụ thuộc (Tải node_modules)
  4. Cấu hình file môi trường (.env)
  5. Khởi chạy dự án ở chế độ phát triển (Development)
  6. Lệnh đóng gói xuất bản (Production Build)
  7. Xử lý các sự cố & lỗi thường gặp (Troubleshooting)
--------------------------------------------------------------------------------

================================================================================
BƯỚC 1: YÊU CẦU MÔI TRƯỜNG MÁY TÍNH
================================================================================
Trước khi cài đặt dự án, máy tính mới bắt buộc phải cài đặt:

1. Node.js (Bản LTS được khuyến nghị):
   - Phiên bản khuyến nghị: Node.js v20.18+ hoặc Node.js v22.12+ (tối thiểu v20.x trở lên).
   - Tải về tại: https://nodejs.org/ (Chọn bản LTS).
   - Sau khi cài xong, mở Terminal / PowerShell / Command Prompt kiểm tra:
       node -v
       npm -v
     (Nếu hiện ra phiên bản v20.x hoặc v22.x và npm v10.x là đã thành công).

2. Git (Tùy chọn nếu clone qua Git):
   - Tải về tại: https://git-scm.com/


================================================================================
BƯỚC 2: CHUẨN BỊ THƯ MỤC MÃ NGUỒN DỰ ÁN
================================================================================
1. Sao chép toàn bộ thư mục dự án sang máy tính mới.
   LƯU Ý: KHÔNG CẦN copy thư mục `node_modules` và thư mục `dist` từ máy cũ sang 
   (vì node_modules rất nặng hàng trăm MB và phụ thuộc vào hệ điều hành/kiến trúc máy).

2. Đảm bảo cấu trúc thư mục gồm có các file quan trọng:
   - package.json
   - package-lock.json
   - vite.config.js
   - index.html
   - src/
   - public/
   - .env (hoặc tạo mới theo Bước 4 bên dưới)


================================================================================
BƯỚC 3: CÀI ĐẶT CÁC THƯ VIỆN (TẢI THƯ MỤC node_modules)
================================================================================
1. Mở cửa sổ dòng lệnh (Terminal / PowerShell / Command Prompt / Git Bash).
2. Di chuyển vào đúng thư mục gốc của dự án:
   Ví dụ trên Windows:
     cd D:\DuAn\cake-shop-frontend

3. Chạy lệnh cài đặt:

   >>> LỆNH CHÍNH THỨC:
       npm install

   >>> TRƯỜNG HỢP GẶP CẢNH BÁO XUNG ĐỘT PHIÊN BẢN GÓI (Peer Dependencies):
   Nếu npm dừng lại và báo lỗi "ERESOLVE unable to resolve dependency tree" do 
   sự chênh lệch giữa các thư viện UI, hãy chạy lệnh với cờ --legacy-peer-deps:

       npm install --legacy-peer-deps

   >>> TRƯỜNG HỢP DÙNG YARN HOẶC PNPM (Nếu máy bạn cài sẵn):
       yarn install
       -- hoặc --
       pnpm install

4. Quá trình tải sẽ diễn ra tự động trong khoảng 1 - 3 phút tùy tốc độ mạng.
   Khi hoàn thành, thư mục `node_modules` sẽ tự động được tạo ra đầy đủ trong dự án.


================================================================================
BƯỚC 4: CẤU HÌNH FILE MÔI TRƯỜNG (.env)
================================================================================
1. Kiểm tra trong thư mục gốc dự án xem đã có file `.env` chưa.
2. Nếu chưa có, hãy tạo một file mới đặt tên chính xác là `.env` (không có đuôi .txt).
3. Mở file `.env` và điền địa chỉ API của máy chủ Backend:

   ----------------- Nội dung file .env -----------------
   VITE_API_URL=http://localhost:8081
   ------------------------------------------------------

   * Chú ý:
     - Nếu Backend chạy trên cùng máy: giữ nguyên `http://localhost:8081`.
     - Nếu Backend chạy trên server nội bộ nhà máy DRC: thay đổi IP tương ứng, ví dụ:
       VITE_API_URL=http://192.168.1.100:8081


================================================================================
BƯỚC 5: KHỞI CHẠY DỰ ÁN (CHẾ ĐỘ PHÁT TRIỂN / DEV)
================================================================================
1. Sau khi cài đặt thư viện thành công, chạy lệnh:

       npm run dev

2. Màn hình Terminal sẽ hiển thị thông báo tương tự:
     VITE v7.1.x ready in ... ms
     ➜  Local:   http://localhost:5173/
     ➜  Network: use --host to expose

3. Mở trình duyệt Web (Google Chrome, Microsoft Edge, Cốc Cốc...) và truy cập:
     http://localhost:5173/


================================================================================
BƯỚC 6: CÁC LỆNH KHÁC HỮU ÍCH
================================================================================
1. Đóng gói kiểm tra bản phát hành (Production Build):
       npm run build
   (File sau khi build tối ưu sẽ nằm trong thư mục `dist/`).

2. Chạy thử bản đóng gói (Preview Build):
       npm run preview

3. Chạy dự án cho các máy khác trong cùng mạng LAN truy cập vào:
       npm run dev -- --host
   (Lúc này Terminal sẽ in ra địa chỉ IP mạng nội bộ để các máy tính hoặc điện 
    thoại khác cùng mạng Wifi có thể mở Dashboard).


================================================================================
BƯỚC 7: XỬ LÝ CÁC SỰ CỐ & LỖI THƯỜNG GẶP
================================================================================

1. Lỗi: "'node' is not recognized as an internal or external command"
   -> Nguyên nhân: Chưa cài đặt Node.js hoặc chưa tích chọn "Add to PATH" khi cài.
   -> Khắc phục: Cài lại Node.js bản LTS từ https://nodejs.org và khởi động lại Terminal.

2. Lỗi: "ERESOLVE unable to resolve dependency tree" khi chạy npm install
   -> Nguyên nhân: Xung đột độ tương thích phiên bản giữa react-router và react-select.
   -> Khắc phục: Chạy lệnh:
        npm install --legacy-peer-deps

3. Lỗi: "Port 5173 is already in use"
   -> Nguyên nhân: Có một tiến trình Vite khác đang chạy chiếm cổng 5173.
   -> Khắc phục: Nhấn 'y' để Vite tự động chuyển sang cổng 5174, hoặc đóng terminal cũ.

4. Lỗi: Không tải được dữ liệu biểu đồ, báo lỗi Network Error / CORS
   -> Nguyên nhân: Backend chưa khởi chạy hoặc sai địa chỉ `VITE_API_URL` trong file `.env`.
   -> Khắc phục: Kiểm tra Backend server đã chạy tại cổng tương ứng chưa và kiểm tra lại file `.env`.

5. Cần cài đặt lại toàn bộ từ đầu (Clean Install) nếu thư mục node_modules bị lỗi:
   Chạy lần lượt các lệnh sau:
   - Trên Windows PowerShell:
       Remove-Item -Recurse -Force node_modules, package-lock.json
       npm install --legacy-peer-deps
       npm run dev
   - Trên Linux / MacOS / Git Bash:
       rm -rf node_modules package-lock.json
       npm install --legacy-peer-deps
       npm run dev
